## 页面与任务

| 页面 | 需要回答的问题 | 检查结果 |
| --- | --- | --- |
| MCP 列表 | 我有哪些连接，哪些位置需要处理？ | 服务为主体；范围、搜索和状态仅筛选数据，不触发写入。 |
| 连接详情 | 用在哪里，配置和连接是否正常？ | 配置、最近检测与客户端状态分开；操作直接放在对应位置。 |
| 导入已有 | 哪些已有条目将交给本应用管理？ | 默认不勾选，保留来源；相同、不同及代理连接分别说明。 |
| 添加与编辑 | 保存什么，什么时候影响客户端？ | 完整页面承载编辑；保存定义与应用配置分开，离开未保存内容有提醒。 |
| 分配与预览 | 会影响哪些工具和项目？ | 先选目标，逐位置预览，确认后才执行；外部变化会阻止过期预览。 |
| 执行结果 | 哪些完成，接下来做什么？ | 失败项可单独重试，成功项不重复写入；客户端加载另行确认。 |
| 检测与冲突 | 问题出在哪里，如何处理？ | 检测具体已配置目标；外改对比提供保留、独立登记或停止管理入口。 |
| 记录与撤销 | 本次改了什么，可以恢复哪些内容？ | 使用快照，保护外部修改和后续复用；不回退整份文件。 |

## 视觉复核

- 与现有界面结合：保留侧栏、品牌、系统字体、浅色画布、蓝色强调和行内工具图标。MCP 在技能预设之后拥有固定入口。
- 视觉主次：服务列表、使用位置和变更内容是主体；不增加装饰统计卡，不为本轮重复设计已有 Skills 页面。
- 对齐与空间：主标题、筛选与内容使用一致边界。分配页采用紧凑服务选择，避免目标工具被长列表挤到页面末尾。
- 颜色：强调色用于主操作和选择状态；告警使用较深文字。配置完成与客户端可用分别表述。
- 数据一致性：待处理数量和筛选使用同一个范围；应用结果按实际目标汇总。
- 窄屏：侧栏折叠，列表改为纵向信息，详情双栏改为单栏；不以横向滚动隐藏关键操作。
- 保留的视觉选择：服务图标框与较小的辅助说明字号沿用已有产品风格。服务名称和操作仍使用更明显的层级；不为自动规则更换整套视觉系统。
