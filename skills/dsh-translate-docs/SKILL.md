# 翻译或同步明确指定的文档

只有用户明确调用本翻译流程时才执行。代码或文档审查、源文件变化、配对哈希过期，都不自动授权翻译。阅读[项目上下文](references/project-context.md)和[文档写作](references/prose.md)。

1. 明确源语言、目标语言、变化的文档，以及项目术语和配对约定。一次修改可以以任一语言为准，不默认英文永远优先。只有双边修改冲突、无法安全选择时才询问，同时继续无歧义文档。
2. 完整阅读相关段落及实际技术上下文。翻译指定变化，并根据连贯性需要处理周边文字；保留结构、链接、代码块、协议标识符、示例和可执行命令。
3. 逐句比较含义：义务、否定、默认值、条件、数值限制、例外和恢复行为。译文应自然，但不能把“禁止”弱化成建议，也不能补造缺失行为。
4. 保留两边各自的独立修改，在具体冲突段落明确解决。完成语义审查后才更新配对元数据；项目已有配对工具时使用该工具。
5. 检查链接、呈现和必需检查。报告翻译路径、源语言方向、术语选择和未解决的歧义。哈希一致只是记录一致，不能证明翻译准确。
