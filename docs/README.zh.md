# Skills Hub

**安装一次，处处可用。**

集中管理你的 AI Agent Skills，按需同步到不同的编程工具和项目。

[官网](https://aiskillshub.link) · [下载安装](https://aiskillshub.link/download) · [使用文档](https://aiskillshub.link/docs) · [浏览合集](https://aiskillshub.link/collections) · [English](../README.md)

## 下载

支持 **macOS、Windows 和 Linux**，前往[官网下载页](https://aiskillshub.link/download)下载安装。

macOS 首次打开若提示“已损坏”或“无法验证开发者”，请查看[安装帮助](https://aiskillshub.link/docs/installation)。

[查看 v1.0.1 发布说明](https://github.com/qufei1993/skills-hub/releases/tag/v1.0.1)

## 你可以用它做什么

- **发现与安装**：在桌面端或官网浏览任务合集，搜索单个 Skill，也可以从 Git 仓库或本地目录导入。
- **多工具同步**：选择目标工具及全局或支持的项目范围，也可以添加自定义目录。
- **批量管理**：整理标签、选择工具、批量启停，或更新选中的多个 Skills，保留原有配置。
- **AI 管理**：让编程 Agent 通过对话安装、更新和整理 Skills，与桌面端共用同一份技能库。
- **设备同步**：通过 GitHub、GitLab 或 Gitee 仓库，在多台电脑间同步 Skill 文件、描述和标签。

## 支持的工具

支持 **48 个 AI 编程工具**，包括 Claude Code、Codex、Cursor、OpenCode 等，也可以添加自定义工具目录。

[查看完整工具支持列表 →](https://aiskillshub.link/docs/tool-paths)

## 开始使用

1. 下载并打开 Skills Hub。
2. 进入「添加 Skills」选择合集，或从 Git、本地目录导入，勾选需要的 Skills。
3. 设置标签、目标工具及全局或项目范围，确认安装。

想通过 AI 管理 Skills，可在「设置 → AI 管理」点击「一键启用」，无需 Node.js 或 npm。详细步骤见[配置指南](https://aiskillshub.link/docs/ai-management)。
