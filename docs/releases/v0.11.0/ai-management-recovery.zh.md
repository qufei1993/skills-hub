# AI 管理诊断与恢复

正式版通过 GitHub 公开资源地址下载匹配的 CLI。草稿版本的资源无法通过该地址下载，即使发布者能够在发布页底部下载。404 也可能表示版本或对应平台的资源不存在，因此界面明确说明这些情况，要求版本公开发布并包含匹配资源，不再建议反复稍后重试。本机 CLI 校验和本次安装失败是两个结果，安装详情现在把二者的关系显示出来。

已停用或未检测到工具的历史同步异常不再阻塞整体就绪状态，其单独诊断与文件继续保留。终端未配置且存在 PATH 冲突时保留修复按钮。启用成功后的列表刷新失败单独提示，不再误报启用失败。官方 Skill 中不再声称启动会自动更新。

回归测试覆盖中英韩下载不可用提示、网络和校验失败分类、PATH 冲突与终端未配置组合、列表刷新失败，以及使用临时目录模拟已卸载和停用工具。草稿阶段的测试不能证明公开发布后的匿名下载已经通过：已有校验有效的 CLI 可以离线使用，首次正式版启用无法从草稿下载。

此前要求的官方 Skill 修改后直接替换仍按用户要求暂停，现有内容校验仍可能阻塞修复。macOS/Linux 终端配置目前支持 Bash、Zsh，Windows 配置用户 PATH；Skill 部署后终端配置失败可能留下部分完成状态，需要处理终端配置再重试。
