# CLI 按需下载验证

桌面安装包不再携带 CLI。在设置中点击启用或更新 AI 管理后，下载桌面要求的固定版本与平台文件，以内嵌的长度和 SHA-256 校验，再通过现有受保护目录与原子替换流程安装。已校验的对应版本可离线复用；启动和状态查询不更新 CLI 或官方 Skill。

## 本机证据（2026-09-30）

- 完整 `npm run check` 与版本检查通过，覆盖下载失败保留旧 CLI、前置检查、进度与重试、不可变资源发布和实物打包检查。
- 发布与 CI 工作流通过 actionlint 1.7.12。
- 开发版进程正常启动；界面自动化未能识别开发窗口，不宣称已完成目视检查。
- macOS ARM 安装包为 **10,728,379 字节（10.23 MiB）**，此前 v0.11.0 为 **16,280,098 字节（15.53 MiB）**，缩小 **34.1%**；实物应用包只含桌面程序，不含 CLI。
- 本机体积验证关闭了更新包签名产物，只是开发验证包，不作为已发布版本或平台签名、公证的证据。

## 构建约束

CLI 使用非默认的 Cargo `cli` feature，由 CLI 准备脚本及完整 Rust 测试启用；桌面打包不启用它。打包工具升级到 Tauri CLI 2.12.0，因为原锁定的 2.9.6 会在二进制发现阶段重新加入被禁用的次要程序。每次打包先清理生成目录，完成后检查实物。

## 远端状态与发布前置条件

公开 [CLI 资源仓库](https://github.com/qufei1993/skills-hub-cli) 已创建，尚未发布 CLI 文件。现有桌面 v0.11.0 仍为草稿，标签未改写。

五平台原生验证、Windows PowerShell 测试、已配置的平台签名与公证、资源令牌的跨仓库权限，以及匿名下载真实 CLI 资源，仍需在 CI 验证通过后才能公开桌面版本。本机结果不能替代这些检查。发布负责人需要先确定包含本次改动的候选版本和标签；旧草稿不能作为本实现直接公开。
