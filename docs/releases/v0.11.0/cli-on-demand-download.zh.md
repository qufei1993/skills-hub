# CLI 按需下载验证

[English](cli-on-demand-download.md) · [版本概览](README.zh.md)

## 当前行为

正式安装包不携带 CLI。点击启用或更新 AI 管理后，下载当前桌面版本和平台对应的文件，校验内嵌长度及 SHA-256，再通过受保护的原子替换流程安装。已校验的匹配版本可离线复用；启动和状态查询不更新 CLI 或官方 Skill。本地测试包内嵌 CLI，具体边界见[本地测试构建](local-test-builds.zh.md)。

CLI 和桌面文件放在原仓库同一个 Release 中。先上传草稿并核对 CLI 摘要，桌面产物完成后一起公开，随后验证匿名下载。草稿重试只补缺少的 CLI 文件，同名不同字节拒绝覆盖，已公开但缺少 CLI 的版本不补传文件。
