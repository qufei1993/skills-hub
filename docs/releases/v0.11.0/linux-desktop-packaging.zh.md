# Linux 桌面打包

[English](linux-desktop-packaging.md)

发布流程新增 Linux x64（`ubuntu-24.04`）和 ARM64（`ubuntu-24.04-arm`），在对应架构的原生机器上构建 `.deb` 和 `.AppImage`。正式安装包不内置 CLI，启用 AI 管理时下载匹配版本的发布 CLI。

安装包命名为 `Skills-Hub-v<版本>-Linux-x64` 或 `Skills-Hub-v<版本>-Linux-arm64`，后缀为 `.deb`、`.deb.sig`、`.AppImage` 和 `.AppImage.sig`。整理资源时要求每种安装包各有一个非空文件，且两种格式的签名均存在；缺失、空文件或混入旧安装包会让构建失败。重命名不会改变已签名安装包的字节。更新清单新增 `linux-x86_64` 和 `linux-aarch64`，使用带签名的 AppImage；另增 `linux-x86_64-deb` 和 `linux-aarch64-deb`，使用带签名的 Debian 包。桌面端按与更新插件一致的系统路径和 dpkg 归属条件识别安装格式，确保 `.deb` 安装更新到 `.deb`、AppImage 更新到 AppImage，符合 [Tauri 更新格式](https://v2.tauri.app/plugin/updater/)。

GitHub 发布页按实际桌面安装包生成中英文下载表格，每种架构一行，列出已生成格式的下载链接。CLI、签名和未生成的安装包不进入表格。表格不写入 CHANGELOG，每次发布自动使用对应标签链接。更新清单单独使用纯变更日志；桌面升级弹窗也会过滤从 GitHub 读取的下载区块，保留版本变更和其他表格。尚未包含此过滤逻辑的旧客户端，在升级前仍可能显示发布页表格。公开下载链接在草稿正式发布后可用；草稿测试仍通过已登录的底部资源列表下载。

`.deb` 通过 Debian/Ubuntu 的包管理安装，AppImage 授予执行权限后运行，并支持应用内更新。两种安装包都基于 Ubuntu 24.04 构建，本次不承诺兼容 Ubuntu 22.04、Debian 12 等旧发行版。AppImage 也受 glibc 兼容性限制，参见 [Tauri Linux 兼容性说明](https://v2.tauri.app/distribute/appimage/)。

Linux 打包 CI 使用 x64、ARM64 原生机器和一次性测试签名密钥，不读取正式发布签名凭据。实际构建两种格式，检查 Debian 包的架构和版本，解包确认均不包含 CLI 可执行文件，并在临时应用数据目录和 Xvfb 中验证 AppImage 能打开桌面窗口。正式发布上传前执行同样的安装包检查；原有 CLI 验证、签名和草稿发布检查保持有效。

本地回归测试覆盖资源整理、缺失/空文件/重复资源、双语表格链接，以及用 Linux 样本执行真实的更新清单生成步骤。实际原生安装包检查在 Linux CI 中运行。本记录不代表现有 v0.11.0 草稿已经重新构建或对外公开。

本地验证：`npm run check` 通过，包括 304 项前端测试、636 项 Rust 单元测试、2 项旧稳定版兼容性测试和 19 项 CLI 集成测试。17 项独立发布回归测试、版本检查、工作流 YAML 解析和 Bash 语法检查也通过。首次完整检查需要为新分支基线重新生成开发 CLI 清单；准备后最终检查通过。

更新说明分离验证：最终 `npm run check` 通过，前端测试增至 308 项，Rust、兼容性和 CLI 测试数量不变。18 项独立发布回归测试全部通过，包括实际执行发布页和更新说明生成步骤。当前分支桌面开发进程成功启动。回归测试确认本地化升级说明过滤下载区块，保留其他表格和代码示例，不会误删后续版本变更标题。

Debian 更新修正：带签名的 `.deb` 使用独立更新目标，按更新插件的包归属条件识别安装格式。回归测试先复现 Debian 签名和目标缺失，再验证修复通过。最终完整检查通过，包括 308 项前端、639 项 Rust 单元、2 项兼容性和 19 项 CLI 测试；18 项发布回归全部通过。合并与发布前由原生 Linux CI 检查实际产物。完整的 Debian 提权升级仍需在草稿验证阶段手动测试。

Windows 发布测试兼容性：完整发布流程发现 Windows Node 通过 `bash -c` 传递多行工作流代码时发生 `sed` 转义错误。回归测试改为将原始工作流代码写入临时脚本再执行，与 GitHub Actions 的执行方式一致；PR 阶段新增原生 Windows 检查，提前执行全部 18 项发布脚本测试。
