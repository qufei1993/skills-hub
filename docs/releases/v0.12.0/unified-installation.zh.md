# 统一安装确认

Git 仓库和本地目录先检测 Skills，再进入确认。单个 Skill 也需要确认。搜索结果直接检测指定来源，然后复用确认步骤。合集直接打开清单。

确认流程分成「选择 Skills → 安装设置」两步。第一步将内容区完整用于清单，第二步显示工具、范围及标签编辑入口。返回保留勾选、搜索与设置，「下一步」不执行安装；合集安装后用完整清单展示进度和失败项；共享目录工具在设置区内确认联动，不叠加弹窗。底部操作保持可见，长清单与设置支持滚动。

返回保留来源、标签、工具、范围及同一来源的勾选；新入口重新建立选择。取消检测后忽略迟到结果。来源对话框关闭后恢复入口焦点。

## 保留的安装规则

- Git 同源检查更新；同名异源、已修改内容和破坏性更新仍受原有服务保护。
- 本地无效条目不可安装，重复名称与多选自定义名称仍校验。
- Git／本地搜索只提交可见选中项；合集搜索不改变安装集合。
- 合集保留同源已有项；新项才添加标签，失败分发重试不重复安装。
- 共享工具按目录去重；项目范围要求目录，不支持项目范围的工具不可选。
- 合集全部成功后刷新列表、关闭弹窗并提示；失败项留在原窗口重试。

使用临时目录和模拟 IPC 进行自动化回归，不修改真实 Skills 或 Agent 目录。桌面人工检查使用真实仓库检测、工程合集预览和临时本地目录，安装链路由临时数据测试覆盖。

## 验证结果

完整检查通过：370 项前端测试通过、1 项按原条件跳过；660 项 Rust 单元测试、2 项自动更新集成测试、19 项 CLI 集成测试通过。桌面开发启动通过。独立复核通过。新增测试覆盖单项确认、返回状态、共享工具页内确认、焦点恢复、取消后晚返回及单项失败重试。

工具与范围常显调整已通过 24 项定向回归及桌面 1180×760／912×640 布局检查，验证项目目录缺失时禁用安装、选择目录后恢复、标签收起后保留名称。完整检查中的 CLI 平台映射测试触发默认 5 秒超时；将测试等待上限设为 15 秒后，370 项前端测试通过，随后构建、Rust 格式／Clippy 和全部 Rust 测试通过。

两步流程补充回归：下一步不安装；返回保留列表勾选、搜索与设置；Git／本地仍仅安装搜索结果中的选中项；切步后键盘焦点留在弹窗内。373 项前端测试通过（CLI 测试使用 15 秒等待上限），原有安装与重试规则保持不变。桌面验证工程合集 31 项清单以及临时本地目录的两步预览，未执行真实安装。

安装设置视觉调整：工具使用自然宽度、等高的紧凑选择项，长名称不再造成行高不一致；标签默认展示，超过 144px 时区域内滚动。工具、标签与范围使用统一浅蓝选中态。

工具多选使用原生方形复选框，避免圆点造成单选误解；紧凑等高布局保持不变。

发现页视觉调整：合集身份使用支持明暗主题的分类色；搜索区域使用浅色底区分。来源弹窗改用紧凑分段控件及更小的表单尺寸，安装行为保持不变。

项目范围布局修复：展开目录区与控件列对齐，最近使用路径左对齐；范围、工具、标签共用响应式标签列宽。

合集、Git、本地来源共用 SkillSelectionList，统一搜索、全选、行布局和简介展开。预览冲突项禁选并从计数及安装请求排除；搜索后的全选仅影响可见且可选的条目，原有各来源提交范围保持不变。回归覆盖冲突项全选及实际 IPC 提交，完整检查通过。

不可用行使用灰底和带横杠的禁用复选框。复选框与标题居中对齐，路径内联省略，悬停可查看完整路径。
