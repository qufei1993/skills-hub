# 合集探索与搜索

「添加 Skills」默认展示官网发布的合集。空搜索用于浏览合集，输入后在同页展示匹配合集与 skills.sh 单个 Skill 结果。Git 和本地导入保留在页头，进入统一安装流程。移除 Top 300 JSON、生成脚本、定时更新工作流、后端读取模块及旧文案。

数据通过应用代理读取 https://skills-hub-collections.qzfweb.workers.dev 。桌面检查小体积 current.json 发布指针，版本未变化时复用已校验缓存；详情按需读取，并固定到索引所属快照。异常响应或离线时回退到已校验缓存。官网没有韩文合集内容，韩文界面使用英文合集内容。

合集搜索仅匹配名称、简介、分类、标签和作者，包含英文翻译，不搜索内部 Skill 内容。已发布索引包含 345 个合集，约 430KB；完整 Skill 详情和安装来源按需加载，不新增动态搜索接口。

首批渲染 12 张合集卡片，滚动接近底部自动追加 12 张；切换搜索恢复首批，从详情返回保留已加载批次。仅在环境不支持 IntersectionObserver 时提供手动加载按钮。

详情页延续分类配色与图标，展示主题标签，相同仓库来源集中展示；窄窗口保持安装入口可用。安装复用本地状态检查、逐项选择、标签、工具分发与失败重试。

桌面验证覆盖 345 个合集中的 12→24→36 滚动加载、搜索过滤、工程合集详情及 31 项安装入口。自动化测试覆盖批次上限、失效滚动回调、搜索重置、快照固定、缓存复用和仅搜索合集元数据。探索页验证未重复安装 Skills。

桌面内合集安装通过 IPC 直接校验清单，支持最多 2,000 个 Skills，保留来源、固定版本、重复项与路径安全校验；外部深链限制保持不变。回归测试覆盖 1,297 项合集，以及不安全或超限清单。
