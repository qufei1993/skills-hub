# 官网合集安装

官网通过 `skills-hub://install?manifest=<编码后的 JSON>` 传递安装清单。v1 清单包含合集标题、固定提交版本的 GitHub 来源，以及选中的 Skill 名称和目录；同一仓库和跨作者组合共用此结构。

打开链接仅校验并显示清单，用户确认后才安装。可以选择工具进行全局分发，默认不选。已有同源 Skills 保留，冲突会提示，分发失败可重试且不重复安装。

协议注册随桌面安装包交付，旧版本需要更新。macOS 单独运行开发进程不会注册系统协议，需要使用应用包验证系统唤起；Windows/Linux 通过单实例机制转交给已运行窗口。后台定时更新进程不受此锁影响。

清单校验拒绝不支持的版本、不安全路径、凭据、多余参数、重复项目或名称、非固定版本及超长请求。接收链接不联网、不访问凭据；确认安装后复用既有安装服务、操作锁和代理设置。无需数据库迁移，不会自动安装。

macOS 收到有效合集链接时自动显示、恢复并置前主窗口，应用已运行或最小化时同样适用；无效链接不会触发窗口激活。

有效合集请求到达时收起空闲的手动添加界面并保留表单值，让合集确认可见；正在执行的操作与其他确认窗口仍先完成，再显示合集确认。

兼容 Windows 和 Unix 的目录分隔符；确认窗口临时让位时保留安装进度与重试记录。
