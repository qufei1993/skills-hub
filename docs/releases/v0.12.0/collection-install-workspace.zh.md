# 合集安装体验优化

合集安装使用清单与设置并排的桌面布局，标题和操作栏固定。清单支持搜索、独立滚动及逐项状态；较窄窗口将设置置于清单之前。遵循现有明暗主题和键盘焦点行为。

安装复用现有仓库扫描、单技能安装、标签和同步命令，以及工具图标、范围选择和项目任务构建逻辑。用户可选已有标签或新建标签，标签仅作用于本次新安装项，并在分发之前保存，便于清理部分成功的安装。已有标签保持不变；已有同源 Skill 保留内容，但仍可分发到选择的工具。

同一仓库固定版本每轮扫描一次；重试重新获取候选清单，已安装项保留 ID，仅恢复标签及分发操作。项目分发缺少目录时禁止开始安装。

官方 Agent 管理 Skill 说明如何解析官网合集清单、保留固定 SHA、复用单技能 CLI 命令及记录部分成功结果，无新增合集 CLI 命令。

同源项使用后端确认的 Skill ID，避免重命名后误分发另一个同名来源。切换全局和项目范围时，工具共享目录的选择保持一致。

验证：`npm run check` 全部通过；新增用例覆盖标签、失败重试、扫描复用、项目范围和同名来源冲突。桌面开发版已重建并启动，使用工程合集清单完成明暗主题、中英韩和窄窗口界面检查。用户手动唤起后发现安装服务拒绝固定版本仓库根链接，31 项均在下载前失败；已补回归并修复。修复后已在真实桌面端验证 `Skills for Real Engineers`：31 / 31 项安装成功，分发到 Claude Code 和 Codex；专用标签 `合集安装测试-20261008` 包含 31 项，技能库总数由 61 增至 92。逐项取消时显示 30 / 31，全选恢复为 31 / 31，安装按钮数量同步更新。

补充修复：安装服务允许 `/tree/<ref>` 形式的仓库根链接，继续要求 `/blob/<ref>/<path>` 包含文件路径；补充固定 SHA 和无效来源回归测试。待安装项仅保留状态文字，移除容易误认为单选框的空心圆。

合集默认全选，支持逐项勾选、全选及部分选中状态。按钮显示安装数量，空选时禁用。搜索不修改选择，安装开始后锁定选择，进度和重试仅包含所选项。

全部所选项成功后，刷新技能库、关闭弹窗并显示成功数量；存在失败项时保留弹窗，重试全部成功后同样自动关闭。

真实桌面端再次完成 31 项安装，确认弹窗自动关闭并出现“合集安装成功，共 31 个 Skills”提示；新安装项继续使用专用测试标签。

打开合集时通过只读本地预检识别已有项和名称冲突，复用普通 Git 安装的来源分类逻辑，无需下载或读取凭据。检查完成前禁用安装；检查失败可重试。预检只用于展示，不作为安装结果，点击安装后仍重新扫描和验证。已有同源项保留内容与标签，可按需分发。
