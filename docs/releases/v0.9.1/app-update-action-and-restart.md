# v0.9.1 应用更新提示与一键重启

## 背景

应用原有的标题栏更新入口尺寸较小，主要依赖图标和系统提示文本表达更新状态。完成更新后，界面只提示用户自行关闭并重新打开应用，缺少直接完成更新流程的操作。

## 改进

- 发现新版本时，标题栏显示使用主题强调色的圆形下载按钮，提高更新提示的可见性。
- 鼠标悬停或键盘聚焦时，按钮展开并显示“更新 / Update”文案。
- 安装过程中持续显示“安装中 / Installing”，避免用户误判当前状态。
- 安装完成后，标题栏入口显示“重启 / Restart”，点击即可重新启动应用。
- 更新完成弹窗的主按钮改为“立即重启 / Restart Now”。
- 完成弹窗仍可通过关闭按钮或背景区域关闭；关闭后不会丢失更新完成状态，标题栏继续提供稍后重启入口。

## 实现

- 引入 Tauri Process 插件并仅注册 `process:allow-restart` 权限，通过官方 `relaunch()` API 重启当前应用。
- 标题栏更新按钮复用现有主题令牌，支持浅色和深色主题、可见键盘焦点及减少动画设置。
- 更新状态、按钮文案、无障碍标签和提示文本均提供中英文翻译。
- 更新下载、签名验证和安装仍沿用现有 Tauri Updater 流程。

## 验收

1. 使用 `v0.8.9` 测试构建真实检测并安装线上签名版本 `v0.9.0`。
2. 验证默认更新图标、悬停展开、安装中和安装完成状态。
3. 验证完成弹窗可以关闭，关闭后标题栏仍显示“重启”。
4. 验证完成弹窗和标题栏的重启入口均可自动重启应用。
5. `npm run check` 全部通过。
