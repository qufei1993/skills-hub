# v0.9.1 Skill 状态准确性改进

## 问题

此前 Skill 卡片、详情页和仪表盘使用的状态判断并不完全一致。来源更新失败和目标同步失败可能只显示为笼统异常，部分工具同步成功、部分失败时也缺少明确区分。点击同步失败的工具还可能进入停用流程，而不是直接重试同步。

工具数量的计算来源也不统一：卡片可能统计历史目标记录，详情页则使用当前检测到的工具列表，导致两个界面展示的已同步数量不同。

## 改进

- Skill 总体状态统一区分已停用、来源错误、同步正常、部分失败、同步失败和尚未同步。
- 工具同步状态统一区分已同步、部分失败、同步失败和未同步，并忽略已停用的目标记录。
- 来源更新错误和目标同步错误会写入托管记录，刷新页面后仍可查看真实失败状态。
- 仪表盘中的活动问题可以直接打开对应 Skill 的更新详情。
- 点击同步失败的工具会重试同步；只有同步正常的工具才进入停用确认流程。
- Skill 卡片和详情页均以当前检测到的工具列表计算状态，卡片明确展示已同步工具数量。

## 验收

1. 已停用、无目标、全部成功、部分失败、全部失败和来源错误的 Skill 均显示对应状态。
2. 来源错误优先于目标同步状态展示，已停用目标不影响健康状态计算。
3. 同一工具存在多个项目目标且结果不一致时显示部分失败。
4. 点击失败工具会重新同步，点击正常工具仍进入停用确认流程。
5. Skill 卡片、详情页和仪表盘对同一 Skill 的状态与工具数量保持一致。
6. 状态计算相关自动化测试及 `npm run check` 全部通过。
