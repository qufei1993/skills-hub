# 技能更新与来源保持一致

技能更新以所选来源为准替换中央技能目录。来源删除或重命名文件时，不再触发 `UPDATE_HELD_BACK` 而跳过更新。手动更新也会覆盖中央副本中的本地修改，并删除来源中不存在的额外文件。

单个更新、批量更新以及同源 Git 重复安装均允许同步来源删除。未被修改的工具副本通过现有分发机制同步删除；工具目标冲突检查、并发修改检测和替换失败回滚保持有效。

更新来源仍须包含 `SKILL.md`；空目录或错误来源目录会在替换中央副本前被拒绝。更新检查保留删除数量字段以兼容现有调用方，`held_back` 返回 false。

回归测试覆盖来源删除、工具副本刷新、Git 重复安装、中央副本本地修改、批量更新和缺少 `SKILL.md`，全部使用临时技能目录。
