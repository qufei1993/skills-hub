# 合集安装工作区

[English](collection-install-workspace.en.md) · [PR #187](https://github.com/qufei1993/skills-hub/pull/187)

## 选择、标签与分发

合集确认使用统一两步流程。默认选中所有 Skills，可逐项取消或全选；搜索保留选择，空选时禁用安装，安装开始后锁定选择。进度与重试仅处理选中项。

可以选择已有标签或新建标签，并设置工具及全局／项目分发。标签在分发前保存，仅作用于新安装项，已有标签保持不变。项目分发必须提供目录。已有同源内容会保留，可使用后端确认的 Skill ID 继续分发。

## 冲突、固定来源与重试

只读本地预检识别已有来源与名称冲突，不下载、不访问凭据。预检完成前禁用安装，执行时再次校验；冲突项不可选、不可安装。

有效的 `/tree/<ref>` 仓库根链接可以安装，修复固定版本来源在下载前被拒绝的问题；`/blob/<ref>/<path>` 继续要求文件路径。同一固定版本仓库每轮扫描一次；重试重新获取候选，保留已安装 ID，继续标签或分发，不重复安装成功项。

所选项全部成功后刷新技能库、关闭确认并显示成功提示；失败项保留在弹窗中供重试，重试全部成功后也会自动关闭。官方管理 Skill 补充通过现有单项 CLI 命令安装固定版本及恢复部分失败的说明。

## 回归覆盖

PR 测试覆盖固定版本与无效来源、来源和名称冲突、预检、标签、扫描复用、仅安装选中项、重试、完成状态及项目目录要求。历史桌面验证完成 Skills for Real Engineers 的 31 项安装、专用标签和 Claude Code／Codex 分发，并检查明暗主题、中英韩及窄窗口。
