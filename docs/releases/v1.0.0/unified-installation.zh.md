# 统一安装确认

[English](unified-installation.en.md) · [PR #187](https://github.com/qufei1993/skills-hub/pull/187)

## 选择与设置

Git 和本地来源先检测再确认，单个 Skill 也适用；搜索结果复用确认流程，合集直接打开清单。三种来源共用「选择 Skills → 安装设置」两步。「下一步」仅进入设置，不执行安装；返回保留勾选、搜索、标签、工具及范围。

共用选择列表提供搜索、可用项全选、简介展开、内联路径和明确的禁用状态。设置使用方形工具复选框、限高滚动标签区和范围控件，共享目录联动在当前窗口内确认。长内容独立滚动，底部操作保持可见。

## 行为与修复

取消检测后忽略迟到结果，避免重新打开确认；关闭来源界面后恢复焦点。合集冲突项取消勾选、禁选，并从计数与安装请求中排除。项目目录和最近路径与其他控件对齐，窄窗口同步适配。

Git 更新保留来源冲突和本地修改保护，本地无效项不可安装。Git／本地搜索仅安装可见选中项，合集搜索保留完整选择。共享工具目录去重，项目分发必须提供目录，不支持项目范围的工具不可选。

## 回归覆盖

PR 测试覆盖单项确认、下一步不安装、返回保留状态、共享工具页内确认、焦点约束与恢复、取消后迟到结果、可用项全选、实际 IPC 提交及失败重试。使用临时来源和模拟 IPC；桌面验证覆盖仓库与合集预览及窄窗口布局。
