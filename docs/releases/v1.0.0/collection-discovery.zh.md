# 合集探索与搜索

[English](collection-discovery.en.md) · [PR #187](https://github.com/qufei1993/skills-hub/pull/187)

## 浏览与搜索

「添加 Skills」默认展示官网发布的合集。空搜索用于浏览，输入后在同页展示匹配合集与 skills.sh 单个 Skill 结果，页头保留 Git 和本地导入。旧 Top 300 数据、生成脚本、维护任务及旧的四合集数据源已移除。

搜索匹配合集名称、简介、分类、标签和作者，包含英文翻译，不搜索内部 Skill 内容。首批展示 12 项，滚动接近底部时追加 12 项；切换搜索恢复首批，从详情返回保留已展开批次。不支持 IntersectionObserver 的环境提供手动加载按钮。

详情使用分类配色、图标和主题标签。同仓库来源集中展示，多仓库条目继续保留各自来源。

## 快照与缓存

通过应用代理读取 `skills-hub-collections.qzfweb.workers.dev`。桌面检查小体积 `current.json` 发布指针，版本未变时复用已校验缓存；详情按需读取并绑定索引所属的不可变快照。离线或响应无效时回退到有效缓存，韩文界面使用英文合集内容。

## 大型合集安装与回归覆盖

桌面内通过 IPC 直接校验安装清单，支持最多 2,000 个 Skills，保留来源、固定版本、重复项及路径检查。官网链接共用清单数量限制，编码后的链接仍不得超过 30,000 字节，详见[官网合集安装](website-collection-install.zh.md)。

PR 验证覆盖 12→24→36 滚动加载、搜索、详情、快照绑定、缓存复用、失效滚动回调和搜索重置。清单回归包含 1,297 项合集、不安全路径及超限数据。
