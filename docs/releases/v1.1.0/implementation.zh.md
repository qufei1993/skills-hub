<a id="library-and-project-management"></a>
## 技能库与项目管理

从选定项目移除部署时，先生成并校验当前范围的计划，通过后直接执行，不增加确认或成功结果弹窗；执行期间保留进度提示，技能库中的 Skill、来源文件及其他位置的部署均保留。冲突或不可操作目标在执行前供用户检查；部分失败或传输结果未知时保留原操作记录及恢复入口，避免重复已完成的写入。

技能库工具图标通过原有命令直接同步、重试或取消同步，普通切换不出现预设、确认或结果弹窗，保留原有共享目录提示。确认该提示时，通过一次部署操作提交明确的工具组，登记提示中的所有工具，失败时整组回滚；未经过该确认的单工具调用仍保留原有显式工具范围。项目／全局筛选限定操作范围，全部视图沿用原有 Skill 范围判定。目标管理和修复保留在当前技能库或 Skill 详情上方的对应弹窗中，普通项目移除直接在技能库执行。修复只展示一个所选位置中的失败工具，不向其他位置新增部署。目标管理同步到选定位置并保留其他部署，移除由工具图标或项目移除入口完成。预设配置仅用于预设编辑与应用。

“我的 Skills”管理已安装内容及其部署位置。同一个 Skill 可以同时用于全局和多个项目；全部、全局、项目视图按这些部署展示，选定具体项目后，列表及工具同步状态都限定到该项目。项目菜单支持搜索，既包含最近项目，也包含已有部署的项目，以易读名称展示并保留完整路径。

项目内通过“管理目标”调整 Skill 的部署位置。移除某个项目部署会保留中央技能内容、全局部署和其他项目部署。组合编辑与预设保存集中在“技能预设”，“我的 Skills”不再重复提供这些入口。AI 设置和本机发现提示独立于技能结果，可以分别关闭，也不计入 Skill 数量；本机发现的导入入口仍保留在“添加 Skills”。

<a id="skill-presets"></a>
## 技能预设

预设保存一套有名称的已安装 Skills 组合，以及每个成员对应的工具，不保存项目目的地。新建、编辑、复制或删除预设只改变定义，不改变已有部署。修改预设不会自动同步此前应用的位置，从预设中移出成员也不会卸载该 Skill；用户需要主动应用修改后的组合，无关部署继续保留。从技能库删除的成员仍保留为可识别的失效引用，不会被静默替换。

“我的 Skills”的批量“工具”保留原有工具分配弹窗，在当前范围和项目筛选内同步勾选的工具、移除取消勾选的工具，不打开或保存预设。

预设卡片仅展示摘要，不再跳转详情页。每行提供编辑、应用和删除入口，“创建副本”位于“更多操作”菜单。编辑页采用上下布局，保存或创建副本后返回列表；成员与工具分配在编辑页查看，每个成员下方直接勾选工具，不再重复展示标签或展开“调整工具”，历史统一在“全部应用记录”查看。成员列表提供全选复选框，展示部分选择状态及当前结果已选数量；新增成员默认分配全部当前可用工具，工具稍后加载时也会默认选中；用户可调整或清空后续新增成员的默认工具，不改写已有成员。全选保留已有工具分配，取消只影响当前结果，保留被搜索隐藏的成员。“应用到”直接打开目标选择弹窗。在同一弹窗中选择全局或一个或多个项目目录，然后应用已保存的成员与工具；按需展开的临时调整仅影响本次应用。后端在写入前检查目标，普通无冲突应用直接进入执行结果，遇到冲突或明确移除操作时才保留确认步骤。冲突反馈显示具体工具、路径和原因，冲突内容保持原样；存在可执行项时，可以继续处理其他项。返回调整时保留已经选择的项目和工具。

应用结果记录各位置的实际情况，包括部分成功和中断。重新检查沿用同一条记录，只处理未完成项，不重复已完成项；编辑或删除预设不会改写历史记录。撤销预览按 Skill 分组并优先使用记录中的名称，按项目或全局范围汇总工具标签，不显示文件路径，将可撤销与受保护部署分区展示数量和保留原因，隐藏零保留数量；同一工具与范围的多条记录可共用标签，部署数量仍统计每条记录；已撤销记录在折叠区查看。分组保留每个目标记录，不改变撤销执行。撤销只移除仍能归属于本次应用的新增目标，保留原有部署、修复的部署、被后续复用的目标，以及内容或身份已经改变的目标。物理目录仍被其他逻辑工具目标引用时继续保留。

历史保留最近更新的 100 条已确认且所有项目均已进入终态的记录；待执行、运行中、中断或状态不确定的记录额外保留，以便恢复。取消尚未执行的预检查会清理临时记录；已经确认或留下写入证据的操作不会被取消清理。历史裁剪不删除已安装文件和后续使用标记，但被裁剪的记录无法再撤销。记录保存或读取历史时执行清理；其他操作持有写锁时仍可查看历史，清理延后执行。保留上限固定，不增加配置项。

<a id="updates-and-recovery"></a>
## 更新与恢复

本次检查失败与重试入口集中在主内容区。侧栏明确标注上次自动更新，只展示数量、时间与“复制运行日志”，不再设置逐项失败列表或折叠详情。复制的运行快照包含统计、结构化失败及待同步工具结果，以及存在时的旧版错误摘要。自动任务仍保留原有进度和当前 Skill 展示。错误色仅突出失败状态和数量，不扩散到其他统计与时间。

“我的 Skills”中的单个和批量更新通过原有更新命令直接执行，不打开差异确认或结果弹窗。保留进度与取消、跳过已停用或未绑定来源的 Skills、部分失败和待同步工具详情，以及失败／未处理项目的重试选择。“更新”页面的查看差异为主动操作，不作为技能库更新的前置步骤。

“检查更新”由用户主动触发，比较已启用 Skills 的来源。进入页面或重启应用只读取保存的检查摘要和时间，不访问来源。每轮检查对同一 Git 仓库与分支只刷新一次，供所属 Skills 共用，并先比较内容，不为所有技能生成完整差异。本地来源在本地检查，Git 检查耗时则受网络影响。完成后持续展示检查数量、有变化与无变化数量、失败情况、时间和实际耗时。再次检查时保留原列表，一个来源失败也不会隐藏其他成功结果。

待更新列表只展示检测到的变化，不罗列整个技能库。“全部更新”处理本轮已确认的候选项；勾选部分项目后变为“更新所选”。查看差异是可选步骤，即使跳过，执行前仍会生成并校验必要计划。缓存、已取消或失效的检查结果不能直接授权更新。批量预览以紧凑清单汇总已预览的 Skills、有文件变化的 Skills 和变更条目；无变化项仅显示简短状态，部署路径仍可展开。批量文件差异默认收起，单个 Skill 的首个文件差异直接展开，不因呈现调整筛掉无变化计划或改变确认行为。差异视图对齐行号、突出增删内容、折叠未变化上下文，并区分文件属性与文本变化。更新支持取消，部分执行结果及部署失败会保留，供后续处理。

内容恢复与部署撤销相互独立。每个 Skill 保留最近一次成功更新前的内容快照及相关来源、版本元数据。恢复前校验当前状态，保留后续新增的部署；已停用的 Skill 恢复后仍保持停用。个人修改会阻止不安全的替换，恢复的版本也不会立即被自动更新再次覆盖。恢复快照位于独立页签；定时更新仍需明确启用，并使用单独的计划和执行记录。

来源修复可以重新绑定已移动或失效的来源，保留中央内容、Skill 身份和部署。缺失部署的修复根据实际故障目标选择位置，复用预览与冲突检查；故障跨越多个范围时，由用户明确选择本次处理范围。

<a id="data-integrity-and-compatibility"></a>
## 数据保护与兼容性

中央 Skill UUID 标识内容。逻辑部署由 Skill、工具、范围和规范化项目路径共同确定，目标 UUID 标识部署代次。注册的工具适配器决定物理路径，共享物理目录不代表共享逻辑归属。主目录展开、路径别名处理和父目录检查继续保护既有部署边界。

预设定义、操作记录和检查摘要使用新增的工作区文档，通过 `schema.workspace` 功能标记管理。共享数据库保持 `PRAGMA user_version=6`，已有 Skill 和目标身份保持不变。预设仅保存在本机，本次没有增加预设同步或预设 CLI 命令。

预览 ID、预期状态和执行回执由后端持有。写入前重新校验来源、内容、目标身份和指纹，并使用跨进程共享操作锁；每项操作分别记录意图和结果。执行结果未知时通过原记录恢复，不新建应用记录重新认领此前新增的目标。手动、批量、自动和 CLI 更新共用内容恢复保护；设备同步及其他写入后的恢复或撤销仍需校验实际状态。历史裁剪保留目标使用标记，避免旧操作重新获得撤销权限。
