# 仓库可见性与凭据访问

选择仓库时保存平台返回的可见性；默认选择器仍只展示私有仓库。
可见性仅展示平台返回的结果，不提供手动选择器。手动地址及旧配置缺少可见性时，提示用户通过现有刷新仓库与选择入口获取平台结果；不提供手动声明或额外验证流程。修改地址会清除之前的可见性和公开上传确认。

- 公开 HTTPS 仓库：只读检查不读取系统凭据，失败不会自动切换到凭据重试。
- 私有或内部 HTTPS 仓库：读取需要凭据；缺少凭据时提示配置。
- 上传：独立处理写入鉴权；公开仓库需先确认 Skill 内容和设备信息的公开风险。
- SSH：使用原有 SSH 身份，不读取 OAuth Token。
- 可见性未知：暂停后台检查与自动同步，设置入口提示确认。

这些标记只保存在本机配置中，不替代远端权限校验；仓库权限变化后需要更新设置。
没有数据库结构迁移，新字段缺失时采用安全默认值。
