# 设备同步：文件保留与工具副本修复

## 根因

上传过滤函数同时用于整体替换中央目录，导致 `dist` 文档和本机 `.env` 等文件被删除。设备同步只更新中央目录，复制型工具目录仍可能保留旧内容；严格目录比较又将 Python 缓存视为用户编辑。

## 修复边界

- 上传不再按 `dist`、`build` 名称过滤正式内容；迁移旧仓库中对应的忽略规则，保留其他自定义规则。
- `.env`、`.env.*`、依赖、缓存等继续不上传，但本机回写保留这些内容。本地符号链接仅复制链接本身，不跟随，不上传。
- 中央目录及活动复制副本先暂存、核对指纹后替换；目标真实编辑或并发写入会阻止覆盖，严格回滚检查不放宽。
- 本机数据库记录绑定目标路径的副本指纹，不含凭据，不上传。副本匹配上次同步内容或当前中央内容时才允许更新。
- Skill、标签、工具状态和副本基线使用统一数据库事务；写入失败回滚已激活的目录替换。此保证适用于进程仍运行时，不构成断电级跨文件系统事务。
- 远端删除冲突可选择使用远端，将本机版本移入应用回收站；两份保留时保留唯一仍存在的本机内容。回收恢复与本机另存不使用上传过滤。
- Python 缓存仅在复制冲突比较中忽略；文档、权限、链接及回滚指纹仍严格保护。

## 验证

临时目录及本地裸 Git 仓库回归覆盖：反复同步保留本机环境文件、正式文档真实写入 Git、旧忽略规则迁移、依赖链接保留、复制更新与真实编辑保护、旧副本基线与正常来源更新兼容、删除冲突回收、元数据失败回滚，以及 Python 缓存误报与回滚并发写入保护。

本次未清理或恢复用户真实 Skill 文件。旧版本已经丢失的文档不会凭空恢复，应在备份后从确认的上游或完整副本恢复。此前生成的测试安装包不包含本修复。
