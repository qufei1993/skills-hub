# v0.10.0 筛选后 Skill 安装范围修复

## 问题与原因

多 Skill 仓库的导入弹窗默认勾选全部候选。搜索后，列表和“已选择”数量只展示匹配结果，隐藏项仍然处于勾选状态。安装处理却从全部候选中读取选中项，因此会出现界面显示“已选择 1 / 1”，实际安装整个仓库的情况。本地目录导入也存在同样的问题。

## 修复行为

- Git 和本地导入弹窗使用同一份筛选后选中列表计算数量，并向安装处理传递明确的候选子路径。
- 安装处理只接受本次提交且仍被勾选的候选；本地导入继续排除无效 Skill。
- 搜索只隐藏候选，不清除原有勾选状态。清空搜索后，所有候选重新显示，并保留此前的勾选或取消勾选结果。
- 无匹配项或当前可见项全部取消勾选时，禁用安装按钮，避免提交隐藏的选中项。

## 验证

新增 17 项弹窗交互回归测试，覆盖 Git 和本地导入：

- 按名称、描述和路径筛选，包含大小写及首尾空白处理；显示 1 / 1 时只提交对应 Skill 子路径。
- 无匹配结果、取消唯一可见项的勾选，以及加载过程中禁止提交。
- 筛选期间取消全选后，清空搜索仍保留其他候选的勾选状态。
- 未搜索时提交全部选中项，本地无效候选不参与提交。

修复前 15 项测试失败，修复后 17 项全部通过。完整 `npm run check` 通过：107 项前端测试、279 项 Rust 测试，以及构建、格式检查和 Clippy。
