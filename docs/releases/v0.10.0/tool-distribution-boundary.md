# 中央库同步与工具分发边界

- 设备同步的合并输入保持中央库与 Git 快照，不包含工具副本。
- 中央库文件和元数据先完成更新，再分发到已登记的 copy 目标。工具异常写入工具记录，不影响云端同步结果；符号链接继续指向中央库。
- 现有 sync_skill_to_tool 命令与设备同步共用 tool_distribution::refresh_copy，正常状态的 copy 不再直接短路。
- 真实副本编辑和跨 Skill 路径共享仍禁止自动覆盖。界面单列具体 Skill 与工具，并提供“我的 Skills”入口；不再将副本异常显示为云端冲突。
- 历史被旧版本过滤的文件不自动恢复，不将未知差异登记成可信基线。
- 测试覆盖真实 Git 仓库中云端成功但副本保留、重复同步、工具问题清除，以及共享 copy 目标。
