# Compact Skill warnings

Skill cards now place a warning icon after the copy button only when attention is needed. Click it to inspect the existing safe error reasons and recovery guidance in a compact overlay. Dismiss it with Escape, the close button, or an outside click. Healthy cards show no warning; issue detection and detail-page notices are unchanged.

## 中文

Skill 卡片仅在异常时于复制按钮后显示警告图标，点击浮层查看原因及处理建议，不再撑高卡片。支持关闭按钮、Esc 和点击外部关闭；正常卡片不显示图标，异常判断与详情页提示保持不变。
