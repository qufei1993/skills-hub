# 精简我的 Skills 顶部

将首页四张统计卡片替换为紧凑的范围筛选行：全部、全局、项目及各自的 Skill 条目数量。数量基于完整托管列表，不随搜索或标签筛选变化。范围按钮复用原有筛选状态，同时移除搜索工具栏中的重复范围下拉框。

存在同步异常时，右侧显示异常 Skill 数量及“查看异常”入口，沿用更新页面跳转；无异常时隐藏提示。使用现有主题变量，窄窗口允许提示换行，按钮支持键盘焦点和选中状态。

本次不修改 Skill 卡片、同步业务逻辑或数据库，也不调整版本号。

## 筛选联动

- 标签及未打标签计数基于当前范围和搜索结果，独立于已勾选标签；标签管理页仍显示整个库的计数。
- 零数量的未选标签禁用，已选标签仍可取消。
- 隐藏项的勾选状态保留，但批量数量、按钮状态、确认内容和实际操作仅包含当前可见的选中项。
- 有筛选时展示结果数量和清除入口；区分整个库为空与筛选无匹配。
- 从标签管理查看指定标签或未打标签项时，重置范围为全部并清空搜索。
- 同步异常提示注明全部范围，沿用原有更新页入口。

## 验证

新增计数和批量数据测试、完整页面交互回归测试；均确认旧行为下失败、修复后通过。运行 `npm run check`，并检查页面布局。
