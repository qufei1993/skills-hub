这套合集交付什么

它不是让 Agent 从一句模糊需求直接冲向写代码，而是建立一条有明确停顿点的交付链：需求阶段先消除歧义，设计阶段确认信息层级和交互，实现阶段保持改动边界，最后用自动化检查和真实界面验收确认结果。

为什么是这 8 条 Skills

01brainstorming把模糊想法转成有边界、有验收条件的需求，避免过早进入实现。
02frontend-design在写界面前建立明确的视觉方向，减少通用模板感。
03executing-plans按已经确认的计划逐步施工，保留检查点和反馈机会。
04browser-control用真实页面验证布局、交互和响应式状态，不只依赖代码检查。
05finishing-branch完成检查、整理改动并形成清晰的交付结果。
